# Smart Rental Hub

Smart Rental Hub is a web-based house rental management system developed as part of the **Enterprise Application Development 2 (EAD2)** module under **HNDSE at NIBM** 💻✨

The system is built using **Java (Jakarta EE – Servlets & JSP), JDBC, and MySQL**, following the **MVC architecture**. It connects **tenants, landlords, and admins** in a single platform, enabling property listings, user interaction, and secure account management to make the rental process more efficient and user-friendly.

---

## 🚀 Key Features

### 👤 Role-Based User System
- Separate access for Tenants, Landlords, and Admins
- Secure login and session management for all roles
- Admin-controlled system monitoring and moderation

---

### 🏘️ Property Management (Landlord Module)
- Add, edit, and delete property listings
- View only own posted properties (Landlord-specific dashboard)
- Manage property details including city, price, type, and images
- Property availability management (active/inactive)
- Full **CRUD functionality for landlords**

---

### 🔍 Property Browsing & Filtering
- Browse properties for all users
- Filter properties by city, price range, and property type
- Like functionality for properties
- Scalable listing system for future enhancements

---

## ✨ System Highlights

## 🗄️ Database Design

- users – Stores user information and roles  
- properties – Stores property listings  
- property_likes – Stores liked properties
